# 用户已确认的长期规则

本文件记录历次可研修改中形成的稳定偏好。除非用户针对新项目明确提出不同要求，否则必须执行。

## 适用范围

- 本技能仅用于国家电网/国网科技项目可行性研究报告。
- 技能触发后，不再进行国网、南网或其他格式判定。
- 禁止套用南方电网的格式和写作规则。
- 严格区分长期规则和项目专属事实，不得把某一项目的地点、业务对象、预算、日期、成果或研究标题固化到其他项目。

## 交付与版本管理

- 用户要求直接在聊天窗口给出文字时，不生成Word文件。
- 编辑Word时，以用户最新修改版为母版，复制并递增`Vn`版本。
- 禁止覆盖原文件，禁止丢弃用户已做的格式修改。
- 除非用户要求，否则不生成PDF。
- 禁止使用computer-use插件。

## 内容写作

- 背景首段必须以核实过的政策或正式文件起笔，并与实际项目建设和需求衔接。
- 项目意义必须形成有实质内容的段落，每段通常达到Word排版后5～6行。
- 正式可研不得出现面向助手的解释、保留意见或免责声明。
- 不得把面向用户的解释性辩护写入报告；需要说明边界时，应通过正式模型定义表达。
- 研究现状必须引用高质量文献，文内编号使用上标。
- 模型类项目的理论依据通常至少2～3页，包含核心公式和完整变量解释。
- 每项研究内容写成一个段落，不在正式研究内容章节机械拆成六个编号点。
- 已确认的内部研究点在技术路线中逐项详细展开，每点按“首先、其次、最后”撰写。
- 禁止按经费金额分配内容和成果。
- 创新点必须面向实际贡献，写清既有问题、新方法和新增能力。

## 图片

- 图片顶部不设总标题，由Word图题提供图名。
- 以文字框和逻辑关系为主，只使用少量图标。
- 严格匹配实际研究层级，不增加装饰性的“形成某某体系”层。
- 分项技术路线图必须写入研究点准确标题。
- 使用彩色、专业、接近高水平科技期刊的视觉标准。
- 放大文字并充分利用框内空间，避免大面积空白。
- 所有箭头和连接线必须对齐。
- 总体技术路线优先采用机制图。
- 后续无关修改不得重绘已经确认的分项技术路线图。
- 中文字体使用微软雅黑、黑体或宋体；英文使用Times New Roman。

## Word格式

- 除非用户要求，否则不保留目录。
- 第一、第二及其他正式标题均不得有首行缩进。
- 图题和表题必须居中且首行缩进为零。
- 最终Word中的公式和数学变量必须由`word-mathtype-native-equations`生成原生`Equation.DSMT4`对象，不得保留LaTeX文本或使用Word OMath。
- 新建国网可研公式采用MathType自动字段按章编号，默认显示为`(3-1)`，对应模板`(#C1-#E1)`；既有报告存在稳定交叉引用时优先保持。
- “式中，”变量解释段落不得有左缩进或首行缩进，变量必须为内嵌MathType对象。
- 必须保留公式、OLE对象、图片、分节符、表格及页眉页脚。
- Word COM必须通过Windows PowerShell 5.1的`-NoProfile -Command`内联调用，不执行`.ps1`文件，不连接或影响用户已有Word实例。
- 表格必须逐单元格检查，不能只看字体和边框。

## 经费

- 材料费、外委研究支出费和外协测试试验与加工费必须严格区分。
- 材料规格应描述功能，不写供应商导向品牌。
- 外委研究必须是边界明确、具有具体输出的支撑性研究任务。
- 外协测试必须写清被测对象、测试范围、量化指标和测试报告。
- 所有明细表必须与汇总金额完全一致。
