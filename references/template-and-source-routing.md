# 国网可研模板与资料选择规则

## 1. Word母版优先级

按以下顺序选择Word母版：

1. 用户为当前项目明确指定的DOCX；
2. 当前项目目录中用户最新手工修改的版本；
3. 用户明确认可的国网科技项目可研模板；
4. 与当前表式版本相同的已确认国网可研，但必须先排除其中全部项目专属内容。

本技能已经限定为国网科技项目，不再执行通用可研类型判定。无法核实国网母版时，只询问一个阻断性的模板选择问题，不自行猜测。

## 2. 资料分类

在项目简报中维护四类资料清单：

- `sgcc_reference_reports`：用于复用结构、样式和写法的国网参考可研；
- `project_materials`：当前场景、既有项目、数据、设备和成果的事实材料；
- `policies_and_standards`：支撑背景与方法的权威政策和标准；
- `literature`：支撑研究现状和理论依据的论文。

禁止用参考可研证明当前项目拥有相同的人员、平台、数据、设备或成果。

## 3. 本地资料检索

- 优先检索用户的本地科研索引，再进行较大范围文件扫描。
- 采用项目名称变体、关键技术、应用地点和文件类型组合查询。
- 只有元数据的检索结果只能证明路径和文件名，不能证明文件内容。
- 以只读方式打开少量、最相关文件。
- 用户明确指定的报告优先于同名或相似标题的检索结果。
- 记录每一份实际使用资料的完整本地路径。

## 4. 新建可研流程

1. 将已确认国网模板复制为`项目名称_V1.docx`。
2. 检查模板并记录样式ID、表格、分节、页眉页脚、媒体和OLE对象。
3. 填写项目简报。
4. 先在Word之外完成内容草稿。
5. 使用模板现有样式和表格结构将内容写入副本。
6. 只插入本项目需要的图片；公式和数学变量交由本技能自动加载的`word-mathtype-native-equations`生成原生`Equation.DSMT4`对象和自动编号字段，用户无需另行调用。
7. 全文搜索源报告遗留的项目名称、地点、单位、日期、金额、成果、人员和对象名称。
8. 分别完成国网结构检查、原生MathType检查和独立后台Word COM复核。

## 5. 既有可研修订流程

1. 同时依据文件名和用户说明判断最新版本；两者冲突时以用户说明为准。
2. 复制为下一版本。
3. 将修改严格限制在用户指定范围内。
4. 保留范围外已经确认的图片和手工格式。
5. 与母版比较DOCX包内组成，并记录预期发生的变化。

## 6. 旧项目内容防残留

根据源模板建立当前项目专用的禁用词清单，包括：

- 旧项目名称及简称；
- 旧申报单位、地点、城市和公司；
- 旧日期和经费金额；
- 旧研究内容标题；
- 旧成果和量化指标；
- 旧产业链对象、设备或数据集。

新报告中上述词语必须零残留；只有经核实确需沿用的内容可以保留。
