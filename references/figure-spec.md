# 国网科技项目可研插图规范

## 1. 总体视觉风格

- 使用彩色，但采用克制、专业的国网/科技配色，保证白色背景上的文字和线条具有足够对比度。
- 以文字框组合和逻辑关系作为主要视觉语言。
- 仅在有助于快速理解时使用少量、含义明确的图标。
- 中文使用微软雅黑、黑体或宋体，英文和拉丁符号使用Times New Roman。
- 图片顶部不得重复设置总标题，图名由Word图题承担。
- 按Word中约160 mm的最终插入宽度检查，确保全部文字清晰可读。
- 所有框、文字基线、箭头、边距及重复间距必须对齐统一网格。
- 连接线优先使用直线或正交折线，避免交叉、回环及装饰性曲线。
- 保留任务要求的可编辑源文件（例如SVG、draw.io、Visio），按Word或其他目标导出高质量图片。仅在当前任务包含绘图或替换图片时执行，用户要求暂不画图时只完成文字。

## 2. 研究内容框架图

- 严格反映已经确认的研究层级，不自行增加成果层或体系层。
- 分区及子框数量服从已确认课题和子研究点，不固定为两项研究内容或六个子点；相同层级保持平行结构。
- 每个主框必须写入研究点的完整、准确标题。
- 使用精练内部文字展示研究任务逻辑和核心输出。
- 只有确有逻辑接口时，才体现研究内容一向研究内容二传递的核算边界、归因结果、潜力清单、评价目标或优先路径等信息。
- 除非“形成某某体系”是已经确认的研究层级或成果，不得在图底部添加此类装饰性框。

## 3. 总体技术路线机制图

- 优先采用机制图，而不是简单六框串联流程图。
- 根据项目至少体现：实际项目对象/数据、评价或诊断机制、内容间耦合接口、场景/优化机制、策略/验证机制及决策结果。
- 确有参数修正和验证反馈时，设置一条清晰的反馈路径。
- 连接线沿固定通道布置，禁止穿越内容框或相互混乱交叉。
- 通过色彩或容器区分研究内容，不使用无关图标进行区分。
- 图中能看出各课题的并行、数据支撑、约束或结果传递关系；不将实际并行任务硬串联。

## 4. 分项技术路线图

- 图的数量和合并方式按当前模板与任务确定；不为每个子点强制制作独立图片。
- 图中必须出现该研究点的完整标题。
- 将实施方案中的实际步骤转化为图中方法和接口，步骤数量按研究逻辑确定。
- 根据研究需要写明方法、模型、变量/公式、约束、输出和验证。
- 构图保持方正、均衡，不在主框右侧额外悬挂孤立输出箭头或输出框。
- 输入/输出横条不是必需结构，仅在能明显提升逻辑清晰度时使用。
- 用户确认某张图后，只做指定局部修改；其他文字修订不得重绘整套已确认图。

## 5. 文字密度与字体层级

- 文字字号必须充足，框内内容应尽量填充，避免大面积无意义空白。
- 每个主步骤优先使用三行精练文字或三条内部条带。
- 避免长段落被挤压成狭窄的竖向文字列。
- 标题字号大于说明文字，同级文字字重一致。
- 图片内公式符号使用Times New Roman。

## 6. 插入Word前检查

按最终插入尺寸检查：

- 按目标插入宽高和字体核对文字是否可读；不因插图检查自动渲染DOCX页面；
- 图片内是否存在与Word图题重复的总标题；
- 研究点标题是否与正文逐字一致；
- 箭头方向和对齐是否正确；
- 是否存在连接线指向空白处；
- 同级框的宽度、高度、圆角和间距是否一致；
- 是否虚构了项目对象；
- PNG长宽比是否与计划插入尺寸一致。

## 7. 图、Word和PPT的内容同步

在项目简报记录图对应的研究点、标题、内容版本、源文件、导出文件、目标尺寸和确认状态。正文方法改变时检查受影响图，按授权范围同步；不把旧图中的文字重新覆盖回已确认的新正文。

转为可编辑PPT时调用对应技能，提供确认后的标题、源文件及目标正文区域；文字、连接线、项目符号和分组由该技能按原生对象合同实现，不能用一张整图冒充可编辑图。拉宽时重排框体和间距，保留字体比例。PPT实现细节不在可研技能重复维护。
